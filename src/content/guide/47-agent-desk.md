# Agent Desk
<!-- part: Making things | order: 47 | slug: agent-desk | route: /agent-desk | tags: agents, Claude, Muse, ChatGPT, owner questions, proof, made not posted, repeating jobs, failed, stuck, answer, retry -->

Agent Desk is the one place to see what Claude, Muse and ChatGPT are holding, what needs the owner, and where their finished work is saved.

## Where to find it

- Side menu or phone More: Content & Production, Agent Desk. An admin controls each person's menu access.
- A brand's Today tab: Agents on this brand, then Open Agent Desk. That link keeps the brand selected.
- Dashboard, Waiting on me: tap an agent ask to open the same task sheet without leaving Dashboard.

## What you see

- The made-not-posted count near the top. Tap it for Social posts, grouped by planned post date and brand, with Drive links. Made posts whose date has passed are late.
- Needs you: one card per ask, oldest first, with a question and its task together. The linked to-do is not repeated. When there is no actual question, What happened shows the agent's own latest words.
- Claude, Muse and ChatGPT cards show working, waiting, stuck and done-this-week counts.
- Stuck and late work, failures grouped by the saved reason, repeating jobs and recently finished work with proof.
- A short scheduled-run health line links to Admin Panel, Crews, using the same health list.
- Filters for agent, brand and status, and title search. This browser remembers Show my tasks. Filters are not sign-in or permission changes.

## Open a task

Tap a row for its instructions, question or latest explanation, dates, proof and full saved history. Old open work never ages off the list. Closed work is kept on the Desk for 60 days; made-but-unposted files stay visible regardless of age. Opening a task loads its history separately, including older answers and notes. The Desk and its task sheet refresh every 30 seconds while open.

## Owner actions

1. Answer: type a reply and send it. The answer lands on the original question or task for the agent to read; the history copy is not another job.
2. Send back: write what needs changing. Hand to agent: choose Claude, Muse or ChatGPT and optionally add a note.
3. Mark done with proof: save the actual work link and optionally a short summary. This never makes a social post count as posted.
4. Mark posted: paste the real live post link and choose its platform. This records what is already live, without publishing from HQ.
5. Cancel stops the task; Retry group sends the failed tasks back for another attempt.

Only admins can use these actions. Brand-assigned people can read their brands' agent work and proof, but cannot answer, reassign, retry or close it. Tasks actively being worked by Content Studio stay locked until that work finishes. The task sheet's Ask about this answers from the saved task context.

## Made versus posted

Drive files mean the piece was made. A live social link means it was posted. Made-not-posted pieces do not appear as finished work in Latest work and do not increase Output. A posted piece counts once for its brand even if it has several platform links, using when it was posted. Finished non-post tasks count as work for all their tagged brands. Today and Portfolio share these rules.

## Related screens

Crews checks whether scheduled runs happened, not a second task board. Content Studio keeps requests with their content item. Dashboard reuses Agent Desk's owner asks and task sheet. Brand Latest work reuses finished mailbox work and proof. Files stay in Drive; HQ stores their links.
