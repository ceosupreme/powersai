# Leak Stack
<!-- part: Clients and leads | order: 76 | slug: leak-stack | route: /leak-stack | tags: leak stack, money leaks, leak estimate, captured revenue, avoided loss, risk exposure, inputs, vertical defaults, proposal, sales prep -->

The Leak Stack estimates how much money a business loses each month to specific problems, called leaks, such as leads that never get a reply. Each leak has its own formula, and the page shows exactly which numbers went into it and where each one came from. Use it before a sales call and as the base for a proposal.

## Where to find it

- On a computer, open "Growth & Marketing" in the side menu and choose "Leak Stack". On a phone, tap "More", then "Leak Stack".
- The page has its own project menu at the top ("Select project"), separate from the header picker. It starts on the first project in the list.

## What you see

- The project menu, a "Run" button (it reads "Refresh" after the first run) and "Generate proposal".
- Before the first run: "No leak stack run yet for this project." If the project's type has no leak checks set up, a message says so.
- After a run: two monthly totals, "Estimated captured-revenue leaks" and "Avoided-loss exposure", then a line with the last run time and how many runs are on file.
- The sections "Captured-revenue leaks" and "Avoided-loss exposure", with one card per leak.
- Each leak card shows the name, a "headline" or "supporting" badge, an "avoided-loss" badge where it applies, a benchmark line, the monthly estimate, a ready-made sentence with a copy button, and "Show inputs".
- A "Proposals" card at the bottom.

## How to use it

### Run or refresh the estimates
1. Choose the project in the page's own menu.
2. Tap "Run" or "Refresh". The message "Leak stack computed" confirms it.

### See where a number came from
1. Tap "Show inputs" on a leak.
2. Each input shows its value and a source badge. "unresolved" means the formula is missing a number, so that leak shows "—" with a reason instead of an amount.

### Use a leak in outreach
1. Tap the copy button next to the sentence that begins "You're leaking an estimated".
2. Paste it into a message, a video script or a template.

### Build a proposal from the run
1. Tap "Generate proposal".
2. Fill in the "New proposal" window and tap "Save draft". The preview opens, ready for "Print / PDF". The "Proposal Pages" article explains the window's fields.

## Words on this screen

- Leak: one way the business loses money, with its own formula.
- Captured revenue: money the business could win back.
- Avoided-loss exposure: risk the business could avoid. It is kept apart from captured revenue so the two are never added together.
- headline, supporting: how central the leak is to the pitch.
- Benchmark: the industry standard the leak is compared with.
- Live signal: a value read from the project's own data.
- Project override, Vertical default, Conservative fallback: a value set for this project, the industry's default value, or a cautious built-in number.
- unresolved: an input with no value, which stops that leak from being priced.

## Good to know

- Every dollar figure is an estimate. The live signals are leads that came through the client's capture link in the last 30 days, after-hours leads, unanswered leads, and the Google rating and review count. Everything else comes from industry defaults.
- There is no field for a project's own average ticket or close rate, so those inputs use industry defaults or the fallback.
- If the project has no time zone, after-hours counts assume Pacific time and show "assumes PT".
- Leak checks come from the project type. Edit them in "Admin Panel", on the "Pillars" tab, under "Project-Type Config", then "Leak Vectors". The page's own hint, "Admin → Project Types", uses older wording.
- Only the latest run is shown. Older runs are counted but cannot be opened.
- The same calculation powers the Prospect Dock checkups and the public free checkup.
