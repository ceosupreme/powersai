# Content Studio
<!-- part: Making things | order: 46 | slug: content-studio | route: /content-studio | tags: content studio, idea bank, templates, research, hooks, script, scenes, production, platform versions, requests, mailbox, guided, draft, save -->

Content Studio helps you create a piece from an idea or a reusable format. It brings your brand's saved ideas, Radar research, creative choices, script and finished files into one guided workspace. It uses the same content items, work plans and review workflow as the rest of HQ.

## Open it

Choose Content Studio under Content & Production in the side menu, or in the phone's More menu. The address is /content-studio. It uses the same access permission as Content and Radar.

Choose a brand at the top. Its existing content items and Radar briefs appear in Your idea bank & works in progress. Search the titles or filter for ideas and Studio drafts.

## Save an idea

Choose Save an idea, give it a working title, add the idea or source link, and choose a starting format. The idea is saved as a real HQ content item. It opens in the Studio so you can develop it now or return later.

Opening an existing idea does not create another copy. Choose a ready format in Your direction before saving a Studio plan; the original idea is already saved. If it needs a work plan, choose Create the linked work plan. HQ uses its shared work-plan builder and finished playbooks to create the steps.

## Start from a template

A template stores the repeatable structure and useful defaults. Choose Create with this format, make the meaningful choices, and enter an episode title. Each choice offers preset options and an input for your own answer. If the template checks repeated combinations, HQ shows matching recent pieces. Change a choice or describe the fresh angle for the new version before creating it. That note stays with this piece and is not reused as a default for future episodes.

Next, the shared work-plan dialog lets you confirm the product type, destination and business goal. Creating it saves a linked content item, production job and a snapshot of the selected template version. The Studio then opens the new piece.

Template labels mean:

- Draft format: a structure being developed. A brand manager or admin can choose Make available after reviewing the recipe. HQ checks that it has a format, product playbook, variable fields and production steps before releasing it. It is not a claim that this format has performed well.
- Ready to try: the reusable recipe is complete enough to test.
- Performance validated: a format supported by recorded performance evidence.

Changing a template later does not silently change work already made from it. Each piece keeps its own template version.

## The six steps

1. Your direction: choose the episode's variables and format. For an original idea, describe the audience, promise and original angle. Choose Guided or Prepare a full draft. Prepare a full draft runs research first when the piece has no sourced findings, then requests the draft after research is successfully saved. If a connection is unavailable or the work needs review, the sequence stops with the reason shown.
2. Research: request fresh research or add findings yourself. Mark each finding as a factual claim or a creative scenario assumption. Give factual claims source links. Saved brand research, audience questions and observed outliers are available here; selecting research includes its record in the brief.
3. Opening: choose among returned opening options or write your own. Record what pays off the opening and the first visual or sound.
4. Script & scenes: write or review the full script, episode structure or finished written content. Save a timed scene and asset plan, plus the call to action. The script checkpoint means you reviewed the creative plan; it is separate from final approval.
5. Make & adapt: save actual output file links and the main caption. Add platform versions with their own opening, caption, adaptation notes and final file. Personal Facebook profile posts remain manual.
6. Review: work through the format's quality checks, then open the existing content review. Finish the actual production stage and approve there. The Production Board and the Studio show the same piece.

Use Save progress to persist changes. The Studio keeps your place so you can reopen the piece later. Choosing the Studio's back button saves your changes before returning to the idea bank.

## What a request does

Request fresh research, Request openings & a draft, Request a draft or revision, Request a complete draft and Request the production package first save the current choices, then create a structured request in the team mailbox. Add special instructions in A note for the next request before requesting.

Queued · awaiting a worker means the request is saved and waiting. It does not mean research, writing or generation has already happened. Research and draft requests start the connected worker after the request is saved. They use your connected research and writing tools. Production requests remain in the mailbox until the production worker claims them. A missing connection or worker error is shown explicitly; you can retry or continue with your own research and writing. Saved requests shows the status and any returned notes or links. Refresh to load the latest requests and results. Cancel an unwanted queued request from its details. For a failed request, Retry with current choices saves a fresh request using the latest brief. A queued research or draft request can also be started from its details.

A request does not purchase AI generation credits or publish anything. Automated mode needs separate explicit activation for a brand, template and destination; choosing a draft does not authorize publishing.

If another editor or worker updates the piece while you have unsaved changes, the Studio keeps your local edits and warns that a newer version exists. Keep any edits you want to retain before choosing Load latest saved version. Saving an older version cannot silently overwrite the newer one.

## Files and review

The production-file links open the existing Drive folders and Content Studio hub. Put the actual export links for the piece in Finished asset links. A folder link on its own is not a finished video, image or written deliverable.

Open content review saves the Studio and opens HQ's existing content workflow. Quality notes and scores advise; they do not decide whether you may approve a finished piece. Scheduling and publishing remain explicit actions with real external confirmation or a live post URL.

## Turn a finished experiment into a template

In Review, choose Save this format as a template. Give it a name and explain when to use it. HQ saves a new draft template for the same brand using the structure and current variable choices as defaults. It does not copy this episode's research claims, script or finished files into the new recipe, and it does not call the template performance validated. Return to the template shelf and choose Make available when the recipe is reviewed and ready to try.

Use real published results to decide which formats deserve reuse. A promising idea, a complete recipe and a measured winner are different stages of learning.

## Record what happened after publishing

In Review, open Record a performance check. Choose a saved published placement or enter the actual live post URL, select the platform and observation date, and record the numbers the platform reports. Unknown numbers stay blank; enter zero only when it is measured. Add a note about what you learned. The result keeps its connection to this piece, template version, variable choices and chosen opening. Recording numbers does not automatically label a format performance validated.
