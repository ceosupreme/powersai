# STM home hero — current brief (Oct 8 2026)

These owner decisions override older story-block plans, layout maps and the previous warm Option 1 hero direction.

- STM is custom-first: marketing, web and digital operations. The home hero shows the breadth of the work. It does not lead with low price.
- Hero service objects use these exact labels: Web Design, Marketing, Sales, CRM, Automation. They are five geometric shapes with live text. No mini-sites, screenshots, icons, coins, trophies, globes, robots or living rooms.
- Look: cool near-black space, white/silver text, blue-white light, restrained copper accents, bold sans type.
- Services → dashboard → phone transformation is reserved for a later service demonstration. It does not go on the homepage. No pinned scroll.
- "Websites that work while you sleep" is for the Website + Backend offer only. It is not the global tagline.
- In the new nav, Packages replaces Pricing. The /pricing URL, prices, Stripe products and contracts stay unchanged. Recommendation for later: put the Packages label on /pricing, or add a separately approved /packages redirect.
- The main action is exactly "Contact Us". It opens a dialog: call first, then email. There is no form, booking or quiz in front of it.
- Nav: Services | Industries | Work | Packages | Blog | About | Contact Us.
