A Website Media area groups slots by page and section. Open the relevant
slot, upload a replacement image or optional video, adjust its focal
point, preview desktop and mobile, and apply the replacement. Revert
restores the previous version. This is the planned UI, not a claim that
this menu already exists.

| **Field group**         | **Purpose**                                                                                                                                                    |
|-------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|

Extend the existing central public-media configuration rather than
scattering image paths across components. Before wiring the owner
editor, inspect the existing upload/storage permissions and reuse them
where suitable. Preserve private Brand Kit data and client data. A
library upload alone does not bind an image to a page; the slot
assignment must be explicit and tested.

Use approved art or a finished native composition in every visible slot.
A missing video leaves the still or interactive walkthrough in place. No
broken media, gray boxes, image-coming-soon copy or inactive Play
buttons. User uploads are optional replacements, not dependencies for
basic page quality.
